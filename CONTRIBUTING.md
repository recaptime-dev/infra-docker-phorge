# Contributing to the project

## Pre-requisites / Preflight Checks

By contributing to the project, you agree and understand the
[Community Code of Conduct] and [the Linux DCO].

To develop on this Docker image, make sure the [Docker Engine on Linux]
or [Docker Desktop] for Windows, macOS and Linux is installed on your
machine. Alternatively, you can open this repository in GitHub Codespaces
or Ona (formerly Gitpod) instead.

[Community Code of Conduct]: https://policies.recaptime.dev/code-of-conduct
[the Linux DCO]: https://policies.recaptime.dev/community/open-source/linux-dco
[Docker Engine on Linux]: https://docs.docker.com/engine/
[Docker Desktop]: https://docs.docker.com/desktop/
